# Landing Page de Advocacia

![React](https://img.shields.io/badge/React-20232A?logo=react\&logoColor=61DAFB)
![Framer Motion](https://img.shields.io/badge/Framer%20Motion-000000?logo=framer\&logoColor=white)
![EmailJS](https://img.shields.io/badge/EmailJS-1A1A1A?logo=maildotru\&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3\&logoColor=white)
![Responsivo](https://img.shields.io/badge/Responsivo-Yes-success)
![Status](https://img.shields.io/badge/Status-Online-success)

Landing page comercial desenvolvida para um escritório de advocacia, com foco em clareza, conversão e facilidade de contato. O projeto foi construído utilizando React e componentização moderna, garantindo organização, escalabilidade e alta performance.

---

## ✨ Funcionalidades

* Formulário de contato totalmente integrado à **API EmailJS**, permitindo envio direto de mensagens.
* Botões de contato rápido:

  * WhatsApp
  * E‑mail
  * Facebook
* Cards informativos com as áreas de atuação.
* Menu responsivo com **Burger Menu**.
* Animações suaves utilizando **Framer Motion**.
* Design moderno, profissional e focado em UX.
* Totalmente responsivo (desktop, tablet e mobile).

---

## 🛠 Tecnologias Utilizadas

* **React.js**
* **Vite**
* **Tailwind.css**
* **Framer Motion**
* **EmailJS**
* **JavaScript ES6+**

## ▶️ Como executar

1. Instale as dependências:

```bash
npm install
```

2. Execute o projeto:

```bash
npm run dev
```
